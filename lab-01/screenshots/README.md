# Screenshots

This folder contains screenshots of the working endpoints for Lab 1.

## Required Screenshots

1. `home.png` – GET / (Welcome endpoint)
2. `about.png` – GET /about (Student information endpoint)
3. `time.png` – GET /time (Current date and time endpoint)
4. `404.png` – GET /unknown (404 error handling)

## How to Capture Screenshots

1. Start the server using `npm start`
2. Open your browser and visit each endpoint
3. Press `Win + Shift + S` (Windows) to take a screenshot
4. Save each screenshot in this folder with the names listed above
